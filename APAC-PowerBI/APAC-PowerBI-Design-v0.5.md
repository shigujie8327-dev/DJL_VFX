# 亚太工厂 MES Power BI 设计 v0.5：页面原型与原生实施规格

日期：2026-10-22。基于《亚太工厂 Power BI 系统设计 v0.1》（含 v0.3 产线视图、v0.4 分层筛选）。本版把前述方案落到两类可评审产出：

1. **页面原型画布**：9 张 1280×720 页面稿（设计总览、P01–P07、P02-L），点击 Play 可沿下钻路径跳转。地址：https://claude.ai/artifact/HBvokgtp3qz6rJfin6T1D6
2. **原生 Power BI 实施规格**（本文）与主题文件 `apac-factory-theme.json`。

所有页面数值都是确定性的示例数据，工厂 A/B/C/D、产线、设备、物料、订单编号均为虚构。本文中的 DAX 是模板，凡写成 `<...>` 的对象名都需要由模型负责人替换为真实度量值或列名。仍未接入 SSAS，也未做业务口径验收。

## 2. 页面框架

画布 16:9，1280×720（Power BI 默认）。每页从上到下使用同一结构：

| 区域 | 高度 | 内容 | Power BI 实现 |
|---|---|---|---|
| 页眉 | 48 | 产品名、页面导航、示例/数据截至标识、中文/EN | 形状 + 页面导航按钮（或逐个按钮的“页面导航”动作）；截至时间用卡片绑定刷新度量值 |
| 范围栏 | 52 | 面包屑、页面标题、本页切片器 | 文本框 + 动态标题度量值；下拉切片器 |
| 主要指标行 | 70–100 | 4–7 张指标卡 | 卡片 / 多行卡片；副标题用度量值返回带单位文本 |
| 分析区 | 余下 | 2–4 个分析视觉对象 | 见第 3 节 |

边距 16，卡片间距 10，卡片圆角 6，边框 #E1E4E8。主题文件里已经写入页面背景、视觉对象背景、边框和字体。

色彩语义（主题 `dataColors` 前三位依此排序）：

| 用途 | 颜色 | 规则 |
|---|---|---|
| 实绩 | #2563A8 | 所有页面一致 |
| 目标 | #374151 虚线或竖线 | 中性参考，旁边写来源（MES / Routing） |
| 低于目标 / 超时 | #B45309 + “▼” + 文字 | 不只靠颜色 |
| 高于目标 | #1D4E89 + “▲” + 文字 | 不使用红绿配色 |
| 第二序列（夜班、可用率损失） | #E08A2E | 与主色明度不同 |
| 未分类 | 灰色斜线 | 纳入总量 |
| 条件组件 / 未核验 | 灰色虚线框 | 不伪装为真实数据 |

## 5. 报表级度量值模板（Live connection）

SSAS Tabular 的 Live connection 允许在报表中新建报表级度量值，但不能新增表或计算列；请在实际 Desktop 版本中确认。原则：OEE、A/P/Q、换型 6 项、停机分钟等核心指标一律复用模型中的度量值，报表层只做差距、文字、状态与保护逻辑。如果某个需求必须新增模型对象（如语言表、目标有效期），交给模型负责人。

以下 `<...>` 为占位符。

### 5.1 目标差距与文字

```DAX
-- 若 [OEE - Percent] 返回 0–1 小数则保留 * 100；若返回 0–100 则去掉
OEE Gap vs MES (pp) =
VAR _act = [OEE - Percent]
VAR _tgt = [<MES 目标 OEE 度量>]
RETURN
    IF ( NOT ISBLANK ( _act ) && NOT ISBLANK ( _tgt ), ( _act - _tgt ) * 100 )

OEE Gap Label =
VAR _tgt = [<MES 目标 OEE 度量>]
VAR _gap = [OEE Gap vs MES (pp)]
RETURN
    SWITCH (
        TRUE (),
        ISBLANK ( [OEE - Percent] ), BLANK (),
        ISBLANK ( _tgt ), "目标未维护",
        _gap >= 0, "▲ +" & FORMAT ( _gap, "0.0" ) & " pp",
        "▼ " & FORMAT ( _gap, "0.0" ) & " pp"
    )
```

Routing 目标另建一组同名后缀 `vs Routing` 的度量，不做两者择一或回退。

### 5.2 未分类原因占比

```DAX
Downtime Unclassified Share =
DIVIDE (
    CALCULATE (
        [<停机分钟度量>],
        KEEPFILTERS ( DowntimeClassification[<原因组列>] = "<未分类值>" )
    ),
    [<停机分钟度量>]
)
```

### 5.3 帕累托累计占比

```DAX
Downtime Cum % =
VAR _cur = [<停机分钟度量>]
VAR _reasons = ALLSELECTED ( DowntimeClassification[<原因列>] )
VAR _all = CALCULATE ( [<停机分钟度量>], _reasons )
VAR _cum =
    SUMX (
        FILTER ( _reasons, CALCULATE ( [<停机分钟度量>] ) >= _cur ),
        CALCULATE ( [<停机分钟度量>] )
    )
RETURN
    IF ( NOT ISBLANK ( _cur ), DIVIDE ( _cum, _all ) )
```

分钟数相同的原因会被同时计入；需要严格排序时，可加入原因名称作为次级排序键。

### 5.4 换型逐次口径（模型已有指标优先）

先用样本对账确认 `[Change Over Exceedance - Minutes]` 和 `[Change Over Adherence - Percent]` 的定义。只有在模型缺少对应口径时，才用以下模板补充：

```DAX
CO Overrun Per Event Sum (min) =
SUMX (
    VALUES ( ChangeOversAndDowntimes[<换型记录唯一键>] ),
    VAR _d = [Change Over Actual Time - Minutes] - [Change Over Target Time - Minutes]
    RETURN IF ( _d > 0, _d, 0 )
)

CO Net Deviation (min) =
[Change Over Actual Time - Minutes] - [Change Over Target Time - Minutes]

CO Within Target Events =
COUNTROWS (
    FILTER (
        VALUES ( ChangeOversAndDowntimes[<换型记录唯一键>] ),
        NOT ISBLANK ( [Change Over Target Time - Minutes] )
            && [Change Over Actual Time - Minutes] <= [Change Over Target Time - Minutes]
    )
)
```

### 5.5 动态标题与上下文文字

```DAX
Title P02 =
VAR _plant = SELECTEDVALUE ( Plant[<工厂名称>] )
RETURN
    IF ( ISBLANK ( _plant ), "请选择一个工厂", "工厂日常运营 · " & _plant )

Context Text P06 =
"期间 " & FORMAT ( MIN ( 'Date'[<日期>] ), "yyyy-MM-dd" )
    & " 至 " & FORMAT ( MAX ( 'Date'[<日期>] ), "yyyy-MM-dd" )
    & " · 工厂 " & SELECTEDVALUE ( Plant[<工厂名称>], "多个" )
    & " · 设备 " & SELECTEDVALUE ( Asset[<设备编号>], "全部" )
```

在卡片和按钮文字中使用“字段值”条件格式绑定上述度量。

### 5.6 调查列表规则文字

```DAX
Investigate Reason =
VAR _gap = [OEE Gap vs MES (pp)]
VAR _unk = [Downtime Unclassified Share]
RETURN
    CONCATENATEX (
        FILTER (
            {
                ( 1, IF ( _gap <= -3, "OEE 低于目标 " & FORMAT ( -_gap, "0.0" ) & " pp" ) ),
                ( 2, IF ( _unk > 0.10, "未分类原因占 " & FORMAT ( _unk, "0.0%" ) ) )
            },
            NOT ISBLANK ( [Value2] )
        ),
        [Value2], "；", [Value1], ASC
    )
```

阈值 −3 pp、10% 为示例，正式值由业务负责人给出并记录在 P07。

### 5.7 明细行数保护与数据新鲜度

```DAX
P06 Row Guard =
IF (
    HASONEVALUE ( Plant[<工厂>] )
        && DATEDIFF ( MIN ( 'Date'[<日期>] ), MAX ( 'Date'[<日期>] ), DAY ) <= 31,
    1
)

Model Refreshed At = MAX ( 'ZREP Refresh Info'[<刷新时间列>] )
```

明细表的视觉级筛选设为 `P06 Row Guard = 1`，并加 Top N 500（按开始时间）。条件不满足时用卡片显示“请缩小到单个工厂、31 天以内”。

## 6. 状态与条件格式规则

| 状态 | 判定来源 | 显示 |
|---|---|---|
| 查询/连接错误 | 视觉对象报错 | Power BI 原生错误提示；P07 说明联系人 |
| 权限不足 | RLS 下无行 | 卡片显示“您没有该工厂的数据访问权限” |
| 未刷新 | `Model Refreshed At` 早于预期阈值 | 页眉标识变为“数据未按时刷新” |
| 无生产 | 计划生产时间为空 | OEE 显示空白，不显示 0% |
| 不适用 OEE | Is OEE relevant = 否 | 从 OEE 视觉对象排除，P03 计数 |
| 目标未维护 | 目标度量为空 | 差距列“—”，标签“目标未维护” |
| 未完整班次 | 当前时间落在班次内 | P02-L 横幅 |

差距列的字体颜色用“规则”条件格式：<0 用 #B45309，≥0 用 #1D4E89；同时度量值文本自带 ▲/▼，满足不只靠颜色。跨工厂视图不使用红黄绿背景。

## 7. 中英文实现

纯 Live connection 下无法在报表里新增语言表。按优先级：

1. 模型负责人在 SSAS 中加一个不关联事实表的语言维度，以及标题/标签度量（如 `Label P01 Title`）。报表用一个“中文 / EN”切片器或书签驱动所有动态文字。
2. 无法改模型时，做成对的中英文页面（P01-ZH / P01-EN …），页眉语言按钮用页面导航；工厂、期间切片器在中英文页面间同步，保证切换语言不丢失上下文。
3. 主数据名称（停机原因、设备描述）的英文需业务确认的映射，不能靠页面语言切换自动翻译。

## 8. 性能与发布检查

- 每页数据视觉对象控制在 12 个以内；指标卡优先用一个多行卡片代替多张单值卡片。
- 不在切片器中放订单号、记录号等高基数字段；明细只通过钻取进入。
- 首页与主要筛选在公司网络实测中位数和 P95（冷/热各一次）；讨论目标沿用 v0.1：首页 P95 8 秒、主要筛选 P95 5 秒。
- 发布到 Report Server 时：使用与服务器版本匹配的 Report Server Desktop；主题 JSON 中较新的属性（如视觉对象边框圆角）在旧版本中可能被忽略，需在目标版本打开确认。
- 发布到 Power BI Service 时：本地 SSAS 需配置本地数据网关及用户名映射，用最终用户账号验证 RLS 结果。

## 9. 评审时请确认

1. 页面层级与下钻路径（设计总览页）是否符合各角色的使用习惯。
2. P01 是否显示区域 OEE 合计；若跨厂重算口径无法证明，改为只显示各厂值。
3. P05 达成率选“按次数”还是“按时间比值”。
4. P02-L 是否作为一期范围；若 SSAS 不能提供当前班次的数据，一期只保留“上一完整班次”和“昨日”。
5. 调查规则的阈值（示例 −3 pp、50%、10%）。
6. 语言实现走模型语言维度还是成对页面。
